# arabic-text-tools

أدوات نص عربي صغيرة، بدون أي تبعيات: تفقيط الأرقام إلى كلمات عربية، وتحويل الأرقام إلى مبالغ بالجنيه المصري، وتحويل الأرقام العربية الهندية إلى أرقام غربية والعكس، وإزالة التشكيل، وتحويل الكتابة الفرانكو إلى حروف عربية.

Zero-dependency helpers for Arabic text: number-to-words (tafqeet), EGP amount wording, Arabic-Indic digit conversion, tashkeel removal, and Franco-Arabic to Arabic script.

## التركيب

```bash
npm install arabic-text-tools
```

أو انسخ ملفات `src/` مباشرة؛ لا توجد أي تبعيات ولا خطوة بناء.

## الاستخدام

```js
import { numberToArabicWords, tafqeetEgp, toWesternDigits, toArabicIndicDigits, stripTashkeel, francoToArabic } from 'arabic-text-tools';

numberToArabicWords(1234);        // 'ألف ومئتان وأربعة وثلاثون'
tafqeetEgp(1250.5);               // 'ألف ومئتان وخمسون جنيهًا وخمسون قرشًا فقط'
toWesternDigits('١٢٣');           // '123'
toArabicIndicDigits('123');       // '١٢٣'
stripTashkeel('مُحَمَّد');          // 'محمد'
francoToArabic('3arabi');         // 'عارابي'
```

## ما تفعله كل دالة

| الدالة | المدخل | المخرج |
|---|---|---|
| `numberToArabicWords(n)` | عدد صحيح من 0 إلى 999,999,999 | العدد بالحروف العربية |
| `tafqeetEgp(amount)` | مبلغ بالجنيه (عدد) | المبلغ بالحروف مع القروش و"فقط" |
| `toWesternDigits(text)` | نص فيه أرقام ٠-٩ أو ۰-۹ | النص بأرقام 0-9 |
| `toArabicIndicDigits(text)` | نص فيه أرقام 0-9 | النص بأرقام ٠-٩ |
| `stripTashkeel(text)` | نص مشكَّل | النص بلا تشكيل ولا تطويل |
| `francoToArabic(text, options)` | نص فرانكو | حروف عربية |
| `normalizeArabic(text)` | نص عربي | نص موحّد للمقارنة (أ/إ/آ ← ا، ى ← ي، ة ← ه، بلا تشكيل) |
| `sameArabicWord(a, b)` | كلمتان | صحيح/خطأ بعد التوحيد |
| `formatWithSeparators(n, sep)` | رقم | نص بفواصل الآلاف |
| `parseArabicNumber(text)` | نص بأرقام عربية أو فاصلة عشرية عربية | رقم |

## سطر الأوامر

```bash
npx arabic-text-tools 1250.5        # ألف ومئتان وخمسون جنيهًا وخمسون قرشًا فقط
node bin/tafqeet.js --words 1234    # ألف ومئتان وأربعة وثلاثون
```

الأمر يطبع رسالة استخدام ويخرج بالرمز 2 عند غياب الرقم أو كونه غير رقمي.

## قواعد وحدود

- **التفقيط**: تجمع المجموعات بحرف الواو، والمثنى والجمع للمئات والألوف والملايين كما هو متعارف عليه في الفواتير المصرية. المبلغ يُختم بكلمة "فقط"، ويُحذف جزء القروش إذا كان صفرًا.
- **نطاق الأرقام**: من صفر إلى 999,999,999. ما فوق ذلك يرمي `RangeError`، والأعداد السالبة كذلك.
- **الفرانكو**: تحويل حرفي للأحرف والأرقام الشائعة (2 ء، 3 ع، 5 خ، 6 ط، 7 ح، 8 ق، 9 ص). لا يخمّن الحركات ولا يصحح الإملاء، وقد يعطي نتيجة غير دقيقة للنصوص الطويلة؛ استخدمه للفهم السريع لا للتحويل الرسمي.
- **إزالة التشكيل**: تزيل الحركات والتطويل وتضغط المسافات المتكررة، ولا تغيّر الحروف.
- **الأرقام العربية الهندية**: الدالة تتعامل مع المجموعتين ٠-٩ و۰-۹ معًا.
- **التوحيد للمقارنة**: `normalizeArabic` يفقد معلومات عن قصد (يوحّد الهمزات والتاء المربوطة والألف المقصورة)، فلا تستخدمه لنص يُعرض للمستخدم، بل للبحث والمقارنة فقط.
- **سطر الأوامر**: `bin/tafqeet.js` يعمل بدون تبعيات، ويطبع رسالة استخدام عند الخطأ.
